# 🌍 Smart AI Tourist Spot Planner

An intelligent, interactive, and AI-driven travel planning application designed to revolutionize how people explore new destinations. This project leverages artificial intelligence to create highly personalized travel itineraries, taking the hassle out of vacation planning.

---

## 🚀 Key Features

*   **Tailored Itinerary Generation:** Uses AI to curate day-by-day travel schedules based on user interests (e.g., adventure, history, food, relaxation).
*   **Smart Spot Recommendations:** Suggests must-visit landmarks, hidden gems, and local dining spots using machine learning/LLM APIs.
*   **Budget Optimization:** Automatically filters and plans activities that align with the user's specified budget constraints.
*   **Route & Time Efficiency:** Optimizes the sequence of places to visit to minimize travel time and fatigue.
*   **Real-time Insights (Optional):** Integrates live data like weather updates, local event timings, and crowd levels.

---

## 🛠️ Tech Stack (Modify as per your project)

*   **Frontend:** React.js / Flutter / HTML, CSS, JS
*   **Backend:** Python (Flask/FastAPI) / Node.js
*   **AI/ML:** OpenAI API / Google Gemini API / Custom ML Recommendation Model
*   **Database:** MongoDB / PostgreSQL / SQLite
*   **Maps API:** Google Maps API / Mapbox (for route visualization)

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
